How

The model fills in a strict JSON schema (OpenAI structured outputs), and our normalizer checks and repairs it. A single tested renderer runs every spec. No generated code. Changes are plain words too: "Add a Sunday 11:00 class. Front-row bikes €4 more."

Stripe Connect
  • Express account per business, onboarding and payouts handled by Stripe
  • Destination charges: transfer_data.destination = the owner
  • Platform revenue: application_fee_amount = 3%
  • Webhooks: session completed, expired (frees the slot), account updated
Supabase · the database is the referee
constraint no_overlap exclude using gist ( business_id with =, resource_key with =, tstzrange(starts_at, ends_at) with && ) where (status <> 'cancelled')

Two people tap bike 3 at the same second: Postgres accepts one, the other gets "just taken". RLS locks every table; one schema serves every kind of business.
