Describe your business. Get booking software that fits it.

A small-business owner writes one paragraph. Fitted turns it into a booking app, whether courts, a bike map or stylists. Customers pay the owner through Stripe Connect, and Supabase makes double bookings impossible.

How it works

AI

A spec, not code

OpenAI structured outputs fill a strict JSON schema; our normalizer checks and repairs it. One tested renderer runs every spec.

STRIPE CONNECT

Paid straight to the owner

Express account per business, Stripe-hosted onboarding, Checkout with a destination charge and a 3% application fee.

SUPABASE

The database is the referee

Postgres stores specs, versions and bookings. An exclusion constraint makes overlapping bookings impossible.

constraint no_overlap exclude using gist (
  business_id  with =,
  resource_key with =,
  tstzrange(starts_at, ends_at) with &&
) where (status <> 'cancelled')
